# InfozaTech Task 5 — Contact Book

A Flask contact book to add, search, and delete contact details. Entries are stored locally in a `contacts.json` file created automatically.

## Run
1. Open this folder in VS Code.
2. Run `python -m pip install -r requirements.txt`
3. Run `python app.py`
4. Visit http://127.0.0.1:5000

Features: contact form, search by name/email/phone/company, delete confirmation, local JSON storage, responsive interface.

Learning demo only: avoid storing sensitive personal data in an unsecured demo app.
