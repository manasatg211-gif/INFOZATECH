# InfozaTech Task 4 — Password Generator

A responsive Flask app that generates customizable passwords using Python's `secrets` module.

## Features
- Choose a password length from 8 to 64 characters
- Toggle uppercase, lowercase, digits, and symbols
- Includes at least one character from every selected character type
- Uses cryptographically secure random selection
- Copy generated password to clipboard
- Responsive blue-and-white UI

## Run locally
1. Open a terminal in this folder.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Run: `python app.py`
4. Open http://127.0.0.1:5000

Keep generated passwords private and use a unique password for every account.
