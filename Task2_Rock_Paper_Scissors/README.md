# HandPlay — Rock Paper Scissors
**InfozaTech Python Internship · Task 2**

Responsive Rock Paper Scissors web game using Python, Flask, HTML, CSS and Bootstrap.

Features:
- Play against a computer with random choices
- Win, loss and draw logic
- Scoreboard and total round counter
- Recent-round history (last 6 rounds)
- Reset game
- Responsive blue-and-white interface

## Run in VS Code
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000 in your browser.
