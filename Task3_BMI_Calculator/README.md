# InfozaTech Task 3 — BMI Calculator

A simple responsive BMI calculator built with Python and Flask.

## Run locally

1. Install Python 3.
2. Open this folder in VS Code.
3. In the terminal run `python -m pip install -r requirements.txt`.
4. Run `python app.py`.
5. Open http://127.0.0.1:5000 in your browser.

BMI formula: weight in kilograms / (height in metres squared).

BMI categories are general adult screening ranges, not a medical diagnosis.
